# نموذج شاشة الوظيفة

نموذج تفاعلي لتطبيق إعلانات الوظائف يقارن بين طريقتين لعرض الوظيفة وبروفايل الشركة:

- **الخيار أ:** بروفايل الشركة يظهر ضبابياً حول الوظيفة، ويزول الضباب عند التمرير.
- **الخيار ب:** الوظيفة أولاً، مع زر «عرض بروفايل الشركة».

تبدأ الصفحة بقائمة الإعلانات. اختر «الخيار أ» أو «الخيار ب» من أعلى الشاشة، ثم اضغط على إعلان شركة.

## التشغيل

موقع ثابت بدون أي أدوات بناء: افتح `index.html` في المتصفح.
