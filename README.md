# نموذج شاشة الوظيفة

نموذج تفاعلي لتطبيق إعلانات الوظائف يقارن بين طريقتين لعرض الوظيفة وبروفايل الشركة:

- **الخيار أ:** بروفايل الشركة يظهر ضبابياً حول الوظيفة، ويزول الضباب عند التمرير.
- **الخيار ب:** الوظيفة أولاً، مع زر «عرض بروفايل الشركة».

تبدأ الصفحة بقائمة الإعلانات. اختر «الخيار أ» أو «الخيار ب» من أعلى الشاشة، ثم اضغط على إعلان شركة.

## التشغيل

موقع ثابت بدون أي أدوات بناء: افتح `index.html` في المتصفح.

## النشر على GitHub Pages

Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
بعد دقيقة يصبح الرابط: https://abdelmajid152.github.io/wsl-prototype/

## قائمة «إضافة إعلان»

صفحة `add-ad.html` تعرض الشاشة الرئيسية، وعند الضغط على زر «إضافة اعلان» تظهر القائمة بحركة. فيها أربعة أشكال للمقارنة:

- **أ:** التصميم الأصلي (لوحة بأزرار نصية).
- **ب:** مجموعات بأيقونات (المقترح).
- **ج:** شبكة بطاقات.
- **د:** قائمة تنبثق من زر +.

رابط مباشر لكل شكل: `add-ad.html#a` و `#b` و `#c` و `#d`.
